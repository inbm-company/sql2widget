동작하는 기능

포함

  • 로그인·토큰 갱신, admin / viewer
  • 대화 CRUD, Mock(또는 LLM 폴백) 채팅
  • Artifact 위젯 + SQL 미리보기
  • Stage 드래그·이동·리사이즈·자동 저장
  • 연결 관리, 역할별 테이블 권한
  • Viewer 전용 /c/:id/view
  • 고객 DB는 SELECT만

제외 · 이후

  • 운영 배포, 실 RAG 고도화
  • 완성 대시보드 템플릿 (현재 규칙: 없음)
  • 카탈로그 밖 차트 자유 생성

아직 안 정한 것

  • Orion 포스터형 템플릿을 넣을지. 지금은 핀보드만.
  • 비슷한 질문이 같은 furniture를 내게 할 유사도 하니스.
  • Circle = ring × size × companion 런타임 카탈로그.
