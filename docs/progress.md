현재 구현·진행 상황·계획을 기능 영역별로 관리한다. 상태는 `완료` / `진행 중` / `검증 대기` / `계획` 네 가지다. 각 행의 `칸반` 열이 `표시`인 항목만 칸반 카드가 되고, `미표시` 항목은 이 문서와 대시보드에만 남는다. 이 문서를 고친 뒤 `python3 scripts/render_docs.py`로 칸반·대시보드를 생성한다.

## 현재 상태

앱은 로그인·프로젝트·대화, 관리자 DB 연결·테이블 권한, 질문 라우팅과 요청 계획 기반 SQL 조회, 결과에 맞는 위젯 생성, 위젯별 현재 데이터 조회, Stage 배치와 Viewer 읽기 전용 화면을 제공한다. 위젯은 결과 값 대신 원본 DB·SQL 정의를 저장하고 표시할 때마다 현재 데이터를 조회한다. 기본 Stage 배치·Viewer 화면은 별도 카드로 두지 않고 [stage.md](features/stage.md)·[viewer.md](features/viewer.md)에 유지한다.

기능 영역: 인증·프로젝트 · DB 연결 · 채팅·에이전트 · 예상 질문 · 위젯·Stage · 외부 연계 · AI 설정 · 배포·운영.

## 계획

2026-10-14 기능 제안 논의에서 정했다. 이름이 `필요성 검토`·`가능성 검토`인 항목은 결정이 완료 기준이며, 구현은 결정 뒤 별도 항목으로 올린다.

| 영역 | 항목 | 업무 정의 | 칸반 |

| 인증·프로젝트 | 관리자 사용자 관리 | 현재 계정은 시드 2개(`admin`·`viewer`)뿐이고 로그인·내 정보 조회만 있다. 관리자가 사용자 추가·비활성화·역할 지정. 프로젝트 공유 등 권한 정합은 사용자 관리 이후에 함께 정리. 추가(2026-10-14): 여러 계정 운영·같은 프로젝트 공동 열람이 필요할 때 의미가 있고 개인 사용이면 불필요. 계정 관리와 공유는 각각 판단 | 표시 |
